# Python Learning Project

This repository contains basic Python scripts and examples to help beginners learn Python programming fundamentals.

## Project Structure

- `Python-basics/`: Contains various Python scripts covering basic concepts.

### Files in Python-basics/

- `comment.py`: Examples of comments in Python
- `datatypes.py`: Overview of Python data types
- `dict.py`: Working with dictionaries
- `hello-world.py`: Simple "Hello, World!" program
- `list.py`: Operations on lists
- `numbers.py`: Working with numbers and arithmetic
- `practice.py`: Practice exercises
- `set.py`: Working with sets
- `syntax.py`: Python syntax basics
- `tuple.py`: Working with tuples
- `type conversion.py`: Type conversion examples
- `variables.py`: Variable declaration and usage

## Getting Started

### Prerequisites

- Python 3.x installed on your system

### Running the Scripts

1. Navigate to the `Python-basics/` directory:
   ```
   cd Python-basics
   ```

2. Run any script using Python:
   ```
   python hello-world.py
   ```

   Replace `hello-world.py` with the name of the script you want to run.
